# Fase 2 — Contenido de las 6 plantas ✅

Objetivo: que el jugador entienda **cómo se hace** cada material.

## Plantas implementadas

- [x] 🟠 **Cemento** — cantera, trituración, prehorno, horno rotativo, molino, silos, calidad, sostenibilidad
- [x] 🪨 **Agregados** — extracción, trituración, zarandeo, lavado, acopio
- [x] 🔵 **Concreto** — dosificación, mezclado, transporte, colocación, calidad
- [x] ⚫ **Asfalto** — secado, mezcla en caliente, transporte, extendido, compactado, RAP
- [x] 🟤 **Roofing** — fabricación, accesorios, instalación, impermeabilización
- [x] 🚂 **Logística** — pedido, planificación, despacho, entrega, reciclaje

## Sistema

- [x] 35 estaciones educativas con texto, "dato clave" e icono
- [x] Kit de construcción reutilizable (`PlantKit.js`): silos, cintas, tanques, camiones, excavadoras, torres, vallas
- [x] Cada estación es un objeto 3D interactuable con su letrero
- [x] Animaciones propias por planta (horno girando, tambores, humo, polvo,alentamiento)
- [x] Contenido traducible por clave (`stations.<id>.*`)

## Contenido

- [x] Textos en 5 idiomas (35 estaciones × 4 campos)
- [x] Datos reales: 1.450 °C en el horno, 42.5 kg por saco, hasta 30 % de RAP, 15 % de CO₂
- [x] Hilo de **sostenibilidad** transversal en todas las plantas
